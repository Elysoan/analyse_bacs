Analyser une base de bacs

  1. Base A : la base de bacs du client (Excel, CSV ou GeoJSON). Sans coordonnées, utilisez « Géocoder les adresses ».
  2. Base B : l'historique des levées (une ligne par levée), ou un autre inventaire de bacs à comparer.
  3. Vérifiez les colonnes proposées, puis lancez l'analyse.

Les fichiers sont traités dans votre navigateur : rien n'est envoyé sur un serveur (sauf les adresses, si vous lancez le géocodage). Un fichier de 800 000 levées prend environ 20 s à lire en Excel, 5 s en CSV.
